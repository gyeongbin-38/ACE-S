# Related Work

The project is informed by several independent lines of work in progressive disclosure, capability routing, hierarchical memory, temporal memory, structural repository context, and plan-aware retention.

Notable projects investigated during design include:

- Ratel — dynamic tool/skill capability discovery.
- Acontext — skill files as an inspectable memory layer.
- memahead — future-plan-aware context retention.
- xMemory — hierarchical memory with progressive expansion.
- context-router projects — budgeted source routing and structural code context.
- Mnemosyne — temporal/supersession-aware memory relations.

No source code from these projects is vendored in this repository. Their ideas are treated as related work and independently synthesized into a portable skill policy.
