# EVIDENCE Manifest

## Load only when

Exact wording, provenance, corroboration, source authority, auditability, or a disputed material claim affects correctness.

## Do not load when

- the task is subjective/creative and no factual support is required;
- supplied context already contains the exact controlling evidence;
- source precision would not change the answer or decision.

## Entry action

Name the material claim that needs support and the minimum evidence fidelity required for that claim.
