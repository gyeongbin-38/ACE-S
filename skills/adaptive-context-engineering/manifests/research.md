# RESEARCH Manifest

## Use when

The next step requires gathering, comparing, or synthesizing evidence across external sources rather than navigating one bounded repository/document.

## Do not use when

- the answer is fully supported by supplied context;
- one repository or document contains the controlling source;
- the user asks only for transformation of supplied text.

## Entry action

Define the claim/question that needs evidence, then retrieve the smallest source set capable of resolving it. Prefer primary or authoritative sources when the claim requires them.

Typical entry fidelity: `INDEX` or `EXTRACT`.

## Open next

If this manifest fits, read only `references/research.md`.

Lazy additions:

- load `manifests/temporal.md` when current/latest state materially affects the claim;
- load `manifests/evidence.md` when provenance, exact support, or conflicting sources matter;
- load `manifests/retention.md` only if research state must survive later workflow stages.
