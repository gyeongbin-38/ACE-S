# DOCUMENT Manifest

## Use when

The needed context primarily lives inside one or more large supplied documents where hierarchy, sections, tables, appendices, or cross-references matter.

## Do not use when

- the relevant passage is already supplied in full;
- the task requires broad external source synthesis rather than navigating a bounded document set;
- repository structure is the primary unknown.

## Entry action

Start from document structure or a narrow locator: TOC, heading, page range, section name, exact term, or cross-reference.

Typical entry fidelity: `INDEX`, escalating only when the target section is identified.

## Open next

If this manifest fits, read only `references/long-document.md`.

Lazy additions:

- load `manifests/evidence.md` when exact clauses/wording or provenance matter;
- load `manifests/temporal.md` when revisions/amendments can change which document state controls;
- load `manifests/retention.md` when findings must survive later steps or handoff.
