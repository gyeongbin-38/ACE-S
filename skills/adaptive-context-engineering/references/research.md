# Research Route

1. Define the decision/question before broad search.
2. Start with primary or authoritative sources where available.
3. Retrieve independent corroboration only when it changes confidence or covers a material gap.
4. Keep evidence grouped by claim, not by browsing order.
5. Use summaries for orientation and raw excerpts for exact or contested claims.
6. Stop when further search is unlikely to change the conclusion.

For fast-changing topics, verify freshness explicitly.
